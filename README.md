# ARNT Academy — arntacademy.ru

Сайт академии английского языка Арины Ткачевой. Чистый HTML/CSS/JS без сборки:
открывается двойным щелчком по `index.html` или с любого хостинга.

## Публикация на arntacademy.ru
1. В панели хостинга (Timeweb / REG.RU / Beget) откройте корневую папку сайта (обычно `public_html`).
2. Удалите файлы прошлой версии сайта (бывшая папка `dist`).
3. Загрузите **содержимое** этой папки: `index.html`, `css/`, `js/`, `assets/`, `.htaccess`, `robots.txt`, `sitemap.xml`.
   Папку `.git` загружать не нужно.
4. Проверьте, что включён SSL-сертификат (https).
5. В Яндекс Вебмастере отправьте `https://arntacademy.ru/sitemap.xml`.

Файл `.htaccess` включает https, убирает www, ставит заголовки безопасности и
перенаправляет адреса старого сайта (`/ielts`, `/about`, `/privacy` и др.) на новые разделы.
Для Netlify / Cloudflare Pages вместо него используется `_headers`.

## Где что менять — всё в `js/data.js`
| Что | Поле |
|---|---|
| Программа месяца, недели, грамматика, картинки недель | `programmes` |
| Форматы и ссылки на Telegram-ботов | `plans` (`url`) |
| Ссылка на пробный урок (ProgressMe) | `trialUrl` |
| Навыки «Что вы получите» | `skills` |
| Основательница, путь, коллаж | `founder` |
| Реквизиты ИП для документов и подвала | `legal` |
| Яндекс Метрика (номер счётчика) | `analytics.yandexMetrikaId` |
| Изображения | `images` + файлы в `assets/img/` |

Новая неделя / программа / урок добавляется одним объектом в соответствующий массив —
страницы строятся автоматически (`js/app.js`).

## Юридическое
- Политика обработки ПДн, согласие (отдельный документ), уведомление о cookie, сведения о продавце — страницы `#/privacy`, `#/consent`, `#/cookies`, `#/legal`.
- Перед переходом в Telegram-бот или на ProgressMe посетитель ставит галочку согласия.
- Яндекс Метрика запускается только после кнопки «Принять» в уведомлении о cookie.
- Шрифты хранятся локально (`assets/fonts/`) — без запросов к Google.

## Выключено до готовности
- Вход, регистрация и личный кабинет: `accountsEnabled: false` в `js/data.js` (для работы нужен сервер).
- Разделы ARNT Editions и ARNT Journal: страницы есть, ссылки на них скрыты.
